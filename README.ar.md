# PES6_LAN_Play

[![English](https://img.shields.io/badge/README-English-0969da?style=for-the-badge)](README.md)

تشغيل PES6 عبر الشبكة المحلية (LAN) باستخدام سيرفر محلي خفيف على جهاز الهوست مع سكربت مساعد لـ Windows XP.

## ما وظيفة السكربت

ملف `pes6_lan.py` يشغّل سيرفر LAN متوافق مع PES6 على جهاز الهوست، ويولّد ملفات مساعدة لجهاز XP.

المهام التي يقوم بها:
- تشغيل نقاط خدمة PES6 المحلية (TCP + STUN)
- إعادة توجيه عناوين gateway/STUN داخل `hosts` للشبكة المحلية
- فتح منفذ UDP المطلوب للعبة ضمن الجدار الناري للشبكة المحلية فقط
- توليد ملفات XP: `PES6_XP_CONNECT.cmd` و `PES6_XP_UNDO.cmd`

## كيف يعمل

1. تشغيل `pes6_lan.py` على جهاز الهوست.
2. السكربت يحدد (أو يستخدم) عنوان IPv4 محلي ومنفذ UDP للعبة (افتراضيًا `5739`).
3. على هوست ويندوز، يمكنه إعداد `hosts` والجدار الناري تلقائيًا (إلا عند استخدام `--no-setup`).
4. يتم توليد سكربتات XP داخل `win_xp_generatedScripts/` (أو المسار المحدد بـ `--output-dir`).
5. تشغيل `PES6_XP_CONNECT.cmd` مرة واحدة فقط بصلاحية Administrator على جهاز XP الضيف.
6. على الجهازين داخل اللعبة: `Network -> (أي كلمة مرور غير فارغة) -> Player -> PES6 LAN -> LAN`.

حاليًا كل الغرف والبروفايلات والإعدادات تحفظ في الذاكرة فقط (RAM) وتختفي عند إيقاف السيرفر.

## التثبيت والتشغيل على الجهازين

### 1) جهاز الهوست (الأساس الحالي: Windows 10/11)

المتطلبات:
- Python 3.x
- صلاحية Administrator إذا أردت الإعداد التلقائي (hosts/firewall)

التشغيل:
```bash
py pes6_lan.py
```

أوامر اختيارية:
```bash
py pes6_lan.py --ip 192.168.1.10
py pes6_lan.py --udp-port 5739
py pes6_lan.py --no-setup
py pes6_lan.py --undo
py pes6_lan.py --debug
py pes6_lan.py --self-test
```

### 2) جهاز الضيف (الأساس الحالي: Windows XP)

المتطلبات:
- لا يحتاج Python
- حساب Administrator

الخطوات:
1. انسخ `PES6_XP_CONNECT.cmd` إلى جهاز XP.
2. شغّله مرة واحدة كمسؤول.
3. ادخل اللعبة ثم وضع LAN كما هو موضح أعلاه.

إلغاء الإعداد على XP:
```cmd
PES6_XP_CONNECT.cmd --undo
```
أو استخدم `PES6_XP_UNDO.cmd`.

## ملاحظة هامة جداً

> **التصميم الأساسي المدعوم حاليًا هو:**
> - **الهوست:** Windows 10/11 (مدعوم)
> - **الضيف:** Windows XP
>
> نرحب جدًا ونشجّع أي تحسينات توسّع دعم السكربت لأنواع/بيئات الهوست المختلفة.
>
> كما نرحب بإضافة ميزة حفظ التقدم والبروفايلات على جهاز الهوست عبر ملف `JSON` بحيث لا تضيع البيانات بعد إيقاف السيرفر.

## الأمان ونطاق الشبكة

- للاستخدام داخل الشبكة المحلية فقط.
- لا تقم بفتح/توجيه المنافذ إلى الإنترنت العام.
- السكربت مخصص لبيئات PES6 المحلية المتوافقة.
